# Hi, I’m Ayoub

I’m building **POS_newone**, a Mac catalog for exploring products in French and Arabic. A barcode can identify a single item or a whole pack. My portfolio shows what that looks like on a real Mac.

**[Visit my portfolio](https://ayoubdev123195.github.io/pos-newone-portfolio/)** · [See the screenshots](https://ayoubdev123195.github.io/pos-newone-portfolio/pages/projects.html)
